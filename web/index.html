OneBot11 连接模式（正向 / 反向 / Docker 容器互联）与安全

支持机器人主动连接 NapCat 容器（正向WS），也支持 NapCat 连接本机器人（反向WS），可自由配置自定义网络地址。

OneBot11 网络通信协议设定

若 NapCat 跑在 Docker 容器并映射了端口，在此填入对应宿主机映射地址或容器IP

默认监听: ws://127.0.0.1:8088/onebot/v11/ws

Docker 容器互联指引

方案 A（正向连接 - 极简）： 在 Docker 启动 NapCat 时映射正向 ws 端口（如 -p 3001:3001），在上方填入 ws://127.0.0.1:3001 并保存，音理会自动发起持久连接！

方案 B（反向连接）： 在 NapCat 容器内的网络配置中添加反向 WS，地址填入：ws://host.docker.internal:8088/onebot/v11/ws（Windows Docker 环境）或填宿主机局域网 IP。
